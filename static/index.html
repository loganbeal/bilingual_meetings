📖 Quick Start Guide

1. Sacrament Meeting: The "main" session auto-starts when the server launches.
2. Connect Displays: Open projector or personal views on any device on the network.
3. Secondary Meetings: Use the Audio Streamer to create sessions (e.g., Sunday School, Elders Quorum).
4. Join Sessions: Each client can select which session to listen to.
